## Descripción

Este proyecto desarrolla una arquitectura completa de Business Intelligence aplicada al análisis de datos de comercio electrónico utilizando el dataset público Brazilian E-Commerce Public Dataset by Olist.

La solución cubre todo el ciclo de vida del dato, desde la integración y transformación de la información hasta su explotación analítica mediante cuadros de mando interactivos y técnicas de Data Science.

Para ello se ha diseñado e implementado un Data Warehouse basado en la metodología Kimball, utilizando un modelo dimensional que integra información de ventas, pagos y valoraciones de clientes. Sobre esta arquitectura se desarrollan procesos ETL en Python, visualizaciones analíticas en Power BI y modelos de análisis avanzado orientados a la segmentación de clientes y la predicción de satisfacción.

## Funcionalidades principales

- Diseño e implementación de un Data Warehouse dimensional.
- Procesos ETL para integración y transformación de datos.
- Dashboards interactivos para análisis de ventas, clientes, pagos y satisfacción.
- Segmentación de clientes mediante clustering.
- Modelos predictivos de satisfacción del cliente.
